# 🎬 Movie Recommendation System

## 📌 Project Overview
The Movie Recommendation System is a machine learning project that recommends movies based on their genres and descriptions. It uses content-based filtering to identify movies with similar features.

## 🎯 Objectives
- Recommend movies based on content similarity.
- Apply Natural Language Processing techniques to movie descriptions.
- Build an interactive interface for users.

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- Gradio
- Google Colab

## ⚙️ How It Works
1. Create a dataset containing movie titles, genres, and descriptions.
2. Combine genres and descriptions into a single feature.
3. Convert text into numerical features using TF-IDF.
4. Calculate movie similarity using cosine similarity.
5. Recommend the five most similar movies.
6. Display recommendations through an interactive Gradio interface.

## 🎥 Features
- Interactive movie selection.
- Five movie recommendations for each selected movie.
- Content-based similarity matching.
- Simple and user-friendly web interface.

## 📊 Dataset
This project uses a sample dataset of 15 movies for demonstration and learning purposes.

## ▶️ How to Run
1. Open the `Movie_Recommendation_System.ipynb` notebook in Google Colab.
2. Run the notebook cells in order.
3. Launch the Gradio application.
4. Select a movie from the dropdown menu.
5. View the recommended movies.

## 📚 Learning Outcomes
- Understanding content-based recommendation systems.
- Working with text data using TF-IDF.
- Calculating similarity with cosine similarity.
- Creating interactive machine learning applications with Gradio.
